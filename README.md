# Secure Network Topologies & Infrastructure Design

## Project Overview
This repository serves as a practical portfolio showcasing **Network Architecture Design, Logical Subnetting, and Hardware Infrastructure Configuration**. 

The designs contained here focus on building resilient corporate local area networks (LANs) that resist external security breaches and maintain optimal data routing paths.

## Tooling & Simulations
- **Cisco Packet Tracer:** Primary environment used to simulate physical switches, routers, endpoints, and server nodes.
- **Protocols Targeted:** Static Routing, DHCP Reservation, VLAN Segmentation, and Basic Access Control Lists (ACLs).

## Academic Integration
- **A-Level Mathematics Application:** Incorporates advanced binary calculations and geometric progression logic required for custom IP Subnet Masking (VLSM), ensuring zero wasted address space across corporate divisions.
- **BTEC Engineering Baseline:** Demonstrates a fundamental understanding of physical topology boundaries, hardware interfaces, and cable deployment schemas.
